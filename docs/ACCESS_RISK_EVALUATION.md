## False positives and false negatives

- Demo false positives: none.
- Demo false negatives: none.
- Holdout false positives: none.
- Holdout false negatives: none.

The evaluator excludes explicit `insufficient_evidence` notes from positive/negative finding tuples and reports their counts separately. The demo includes benign recently granted access, an approved unexpired temporary grant, and a missing log-coverage case; the coverage case produces a note rather than an unused-access claim. Holdout labels were generated before running the evaluator; no thresholds were changed to fit holdout results.
